## 一、 AI 串行流水线与状态机编排（Comic Pipeline）

线上 API 仅提供单点能力，无法直接生成完整成片。开发者必须编写全套**多阶段串行与并发流水线引擎**：

### 1.1 多阶段状态机控制
- **状态流转**：`LLM 剧本生成 → 逐镜文生图 → 逐镜 TTS 配音 → 逐镜图生视频 → 视音频剪辑拼接 → 封面生成与入库`。
- **阶段依赖校验**：确保前置阶段无误后再触发下一阶段（如：必须在 LLM 结构化 JSON 校验通过后才发起文生图；必须在分镜图片和音频生成完毕后才发起 FFmpeg 拼接）。

### 1.2 Prompt 工程与结构化 JSON 校验
- **Prompt 组装**：针对 LLM 编写结构化 Prompt，强制要求返回包含镜头语言、拍摄手法、情节对白、角色说话人的结构化数据。
- **解析与兜底机制**：开发 JSON 清洗器，剔除 API 返回字符串中的 Markdown 标记与冗余字符；配置 Schema 校验与解析失败时的自动重试逻辑。

### 1.3 跨镜角色形象一致性控制
- **素材关联**：用户创建角色时，保存特征参考图及 Seed 随机种子。
- **动态组装**：在逐镜文生图请求时，自动从素材库检索角色参考图，组装到 API 请求体（Ref Images / ControlNet 参数）中，保证同一角色在不同分镜画面中的视觉一致性。

## 二、 高并发异步任务队列与长任务轮询架构（BullMQ）

视频生成与漫剧合成通常耗时 1–10 分钟，**禁止采用 HTTP 同步等待**，必须开发完整的异步调度与轮询机制：

### 2.1 双异步队列调度
- **队列拆分**：按任务属性与成本拆分为 `comic-pipeline`（漫剧流水线）与 `video-generate`（单视频生成）两条 BullMQ 队列。
- **保护机制**：配置 Worker 并发限流、任务超时防爆（如视频任务 30 分钟 TTL）以及指数退避重试机制。

### 2.2 长任务“二级轮询”与 Webhook 监听
- **异步轮询**：视频生成 API 均为异步长任务（提交仅返回 `supplierTaskId`）。Worker 必须开发定时轮询器（每 10 秒发起一次状态查询），或开发 Webhook 接收端以处理供应商的回调通知。

### 2.3 实时进度平滑计算算法
- **进度映射**：根据流水线阶段设置权重（剧本 5% → 出图 45% → TTS 70% → 视频 90% → 剪辑 100%）。
- **缓存推送**：计算平滑进度并写入 Redis 缓存，提供高性能接口供小程序前端高频轮询。

## 三、 音视频自动化处理与合成引擎（FFmpeg）

独立的图片、音频与短视频片段最终需组装为成片，全套剪辑渲染逻辑由开发者自主实现：

### 3.1 多轨道音视频自动化拼接
- 调用 `FFmpeg` 命令行或封装库，将逐镜生成的短视频（或静态图演播）按分镜顺序进行时间轴拼接与帧率统一。

### 3.2 音轨混合与对齐
- 将各分镜生成的 TTS 语音文件挂载到对应时间轴，与背景音乐（BGM）混合，处理音量比例与淡入淡出。

### 3.3 水印与合规角标强制烧录
- 对齐《人工智能生成合成内容标识办法》，通过 FFmpeg 在视频右上角/右下角**强行烧录“AI 生成”显式水印**，确保存储与播放的合规性。

## 四、 第三方 AI 统一网关与熔断降级链（AI Gateway）

第三方 API 存在不可控的超时、限流（429）、服务中断或调价风险，必须开发统一接入网关：

### 4.1 多供应商降级链与自动切换
- **降级配置**：
  - **LLM**：豆包 $\rightarrow$ DeepSeek $\rightarrow$ 通义
  - **文生图**：即梦 $\rightarrow$ 万相 $\rightarrow$ Stable Diffusion
  - **视频生成**：Seedance $\rightarrow$ 可灵 $\rightarrow$ 备用供应商
- **无感重试**：当主供应商接口超时或报错 5xx 时，网关自动捕获并无感切换至备用供应商重试。

### 4.2 资源自动转存对象存储（COS）
- 供应商 API 返回的原始文件 URL 通常有较短的有效访问期限。Worker 完成生成后，必须自动将文件下载并**转存至自有的腾讯云 COS**，回写永久 URL 至数据库。

### 4.3 成本护栏与平台限流
- **用户级限流**：限制单用户同时并发的生成任务数，防范恶意刷量。
- **平台熔断**：配置每日 API 消费上限金额，达到阈值后自动暂停新任务入队并提示排队。

## 五、 积分/额度原子预扣与回退机制（两阶段扣费）

AI 生成成本相对较高，必须保证账务流水的强一致性与防超扣能力：

### 5.1 两阶段冻结机制（Freeze & Commit）
- **创作提交**：执行 SQL 单条 UPDATE 原子冻结额度（`frozen = frozen + cost`），余额不足直接拦截。
- **生成成功**：生成完成后，正式扣除余额并解冻。
- **生成失败/超时**：自动触发解冻回退，退还冻结额度，防止因第三方 API 异常导致用户额度白白扣除。

### 5.2 多资源优先级扣减逻辑
- 编写多资源扣减逻辑，按优先级依次扣减：`① 会员每日免费额度 → ② 购买的次数包 → ③ 账户积分折算`。

## 六、 前端 AI 创作交互 UI（UniApp-X）

小程序前端必须为 AI 场景开发专门的交互组件与状态响应逻辑：

### 6.1 剧本与分镜可视化编辑器
- **交互控制**：支持分镜卡片拖拽排序、增删分镜、镜头语言（推/拉/摇/移）配置以及单镜独立重生成。
- **模式切换**：支持单个分镜在“文生图合成”与“直接文生视频”生成模式之间自由切换。

### 6.2 异步生成进度与状态机 UI
- 开发高频轮询组件（2s/次），实时拉取最新阶段与进度，配合平滑动画与友好提示文案（如“正在生成第 3/5 镜画面...”）。

### 6.3 “做同款”参数反填
- 快速解析广场作品中的 Prompt、Seed、运动强度与风格配置，一键跳转并反填回创作页面。

## 七、 内容合规风控与后台 AI 成本看板（Admin）

### 7.1 前置与后置内容安全风控
- **前置过滤**：对接微信内容安全 API（`msgSecCheck`），在提交给第三方 API 前拦截敏感 Prompt。
- **后置校验**：作品公开至广场前，校验强制水印标识（`ai_marked=1`）及图片/视频合规审核。

### 7.2 AI 成本与调用数据看板
- 开发后台可视化图表，实时监控各 AI 供应商的调用次数、成功率、平均耗时、失败率及每日消费成本金额。

## 八、 开发工作量占比总结

| 模块 | 核心工作内容 | 预计工程量占比 |
| --- | --- | --- |
| **第三方 AI API** | 提供基础的大模型、出图、出声音、出视频接口 | **10%** （纯接入） |
| **AI 流水线与调度** | 状态机编排、BullMQ 异步队列、长任务轮询、平滑进度 | **30%** |
| **音视频剪辑合成** | FFmpeg 自动拼接、配音对齐、BGM 混合、水印烧录 | **20%** |
| **网关/一致性/风控** | 降级熔断、COS 转存、积分两阶段扣费、内容安全 API | **20%** |
| **前端交互与后台** | 分镜编辑器、轮询 UI、做同款、AI 成本看板 | **20%** |

> **结论**：在 AI 漫剧与视频创作小程序中，**第三方 API 仅仅提供了原材料**，真正支撑业务运转的**流水线编排、长任务调度、音视频剪辑合成、账务一致性与网关防护**（占总体开发量的 90%）均需由开发者自主设计并开发完成。
