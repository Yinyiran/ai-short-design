# AI 漫剧创作小程序 · 统一版本功能梳理

> **版本定义**：单一版本，不再区分窄版/宽版。范围 = 漫剧创作完整链路 + 文生视频 + 图生视频 + 积分中心。
> **定位**：用户用 AI 生成拟人化动物漫剧短视频（写剧本 → 建素材 → 编分镜 → 合成出片），同时提供独立文生视频/图生视频工具，以「会员套餐 + 次数包 + 积分中心」变现。

---

## 一、页面结构总览（底部 4 Tab）

| Tab | 页面 |
| --- | ---- |
| 首页 | 首页（Banner + 创作入口 + 漫剧精选瀑布流）→ AI 写剧本 → 素材库 → 分镜编辑 → 视频风格 → 漫剧合成（进度） |
| AI 视频 | AI 视频首页（双入口 + 视频画廊）→ 文生视频创作 → 图生视频创作 |
| 作品 | 我的作品 → 作品详情 → 作品广场 |
| 我的 | 个人中心 → 会员套餐/次数包 → 积分中心 → 订单中心 → 分销推广 → 设置 |
| 通用 | 视频播放器、微信登录弹层 |

## 二、功能模块清单

### 1. 登录账号
- 微信一键登录（`wx.login` 换 openid，无感续期）；游客可浏览，创作/付费时弹登录
- 头像昵称授权与修改；JWT 双 token 会话安全

### 2. 首页 / 创作入口
- Banner 轮播（后台可配）；三入口卡片：AI 写剧本 / 我的素材 / 开始创作（继续草稿）
- 漫剧精选：热门/动漫/古风/现代分类，双列瀑布流，下拉刷新 + 上拉加载；空状态引导

### 3. AI 写剧本
- 输入主题/类型/目标集数（5–15 分镜限幅）；语言模式：人话 / 人话+喵汪 / 汪喵+旁白
- AI 输出结构化分镜剧本（镜头、拍摄手法、情节、对白、说话人）；支持局部改写、保存草稿、失败重试

### 4. 素材库与文生图（角色一致性）
- 角色/场景/道具三 Tab；创建角色：名称 + 物种 + 「拟人化四足站立」开关 + 描述 → 文生图 4 候选 → 选图入库
- **跨镜角色一致性**：角色图作参考图沉淀素材库，后续分镜出图均携带 ref 图保同一形象；单张失败可单独重试
- 支持上传自有图、生成结果一键存素材、设公开进素材池

### 5. 分镜编辑
- 5–15 分镜网格/时间轴，拖拽排序、增删
- 每镜选角色/场景/道具、改 prompt、换素材、单独重生成、调镜头描述（推/拉/特写）
- **画面生成方式切换**：每镜可选「文生图（默认，合成期统一图生视频）」或「直接文生视频」（会员差异化能力）
- 整剧预览（分镜序列 + 配音试听）

### 6. 视频风格
- 官方内置风格（治愈手绘/热血漫画/国风水墨等）+ 用户自定义风格（审核后公开）
- 参数：滤镜、转场、比例、运镜、BGM 类型；风格可筛选广场

### 7. 漫剧合成链路
- 一键合成：逐镜画面 → 图生视频 → 多角色 TTS 配音 → 拼接转场 + BGM + 片头片尾 → 成片
- 分阶段进度条（剧本→画面→配音→合成）；单镜失败自动重试 2–3 次，仍败给「重试失败镜/整体重试」
- 提交前展示预计消耗额度，预扣失败回退；成片强制烧录「AI 生成」标识不可关闭

### 8. 文生视频（新增）
- AI 视频 Tab 独立入口：文字描述 + 风格/运动幅度 + 时长（默认 5s）+ 比例（9:16/16:9）+ 负向提示词
- 异步生成 + 进度展示；预览/重新生成/下载/保存作品/设公开；**做同款**一键复用参数
- 结果可一键「存为素材 / 作为漫剧分镜画面」，与漫剧链路互通

### 9. 图生视频（新增）
- 独立入口：上传静态图 → 动效视频；运动描述（可选）+ 强度滑块 + 时长/比例
- 输入图可来自素材库角色图（让角色"动起来"）；结果处理同文生视频
- 同时作为漫剧合成链路的逐镜片段生成器

### 10. 视频复刻
- 上传参考视频 → 提取风格/运镜 → 套用到新创作内容（原窄版能力，保留）

### 11. 积分中心（买/兑/赠/耗）
- **买**：积分包档位充值（微信支付，即时到账）；**兑**：积分换次数包/会员（后台配置比例）
- **赠**：好友转赠，单笔/单日上限防刷，事务双写；**耗**：每次 AI 生成按类型扣积分，预扣失败回退
- 明细：收入/支出筛选，逐条流水（类型/金额/余额/关联业务/时间）
- 补充来源（可选）：看激励广告得积分、后台活动补偿（记流水）

### 12. 视频播放器
- 播放/暂停、进度拖拽、倍速（0.5–2x）、全屏、竖屏适配；多集漫剧选集、断点续播
- 常驻「AI 生成」角标不可关闭；播放页提供重新生成/点赞/分享

### 13. 作品 / 广场
- 我的作品：全部/图片/视频 Tab，状态（生成中/完成/失败）、详情（参数与消耗）、重生成、保存素材、删除
- 广场：公开作品双列瀑布流，点赞/浏览/分类筛选/做同款；公开需过审（ai_marked=1 强制）
- 发布控制：公开/私密；保留期后台可配

### 14. 会员套餐 / 次数包
- 月/季/年卡权益对比（每日生成次数、高级风格、去广告）；微信支付即时生效、到期自动降级提醒
- 次数包：一次性次数（含赠送），长期有效，与会员额度并行

### 15. 分销推广
- 推广码/链接；二级分销（A→B 两级，代码强制 ≤2 级、防自邀防环）
- 佣金明细、提现申请与记录

### 16. 个人中心 / 订单 / 设置
- 我的页：头像、ID、会员状态、余额（积分/次数）、功能入口
- 订单中心：充值/购买记录，状态筛选（待支付/已支付/已取消/已退款），详情含订单号/微信交易号
- 设置：隐私、关于、客服（FAQ + 反馈）、退出登录

## 四、额度资源模型（积分 × 会员 × 次数包）

| 资源 | 性质 | 来源 |
| --- | --- | --- |
| 会员免费额度 | 订阅期按日/月发放 | 购买会员 |
| 次数包额度 | 一次性、长期有效 | 现金购买（含赠送） |
| 积分 | 通用货币 | 购买/兑换/赠送/活动 |

**扣减优先级**：每次 AI 消耗 → ①会员免费额度 → ②次数包 → ③积分折算 → ④全无则拦截并引导「购买次数包/兑换积分/开通会员」三选一。

**消耗定价表（后台可配，示例）**：写剧本 0.5 次/10 分；文生图 1 次/10 分；TTS 0.5 次/5 分；图生视频 1 次/20 分；文生视频 1 次/20 分；整剧合成按分镜累加。

## 五、关键设计判断

1. **双通道设计**：文生视频/图生视频 = 漫剧链路内嵌（分镜生成方式可选）+ 独立创作入口，共用同一套队列/进度/额度/存储/水印底座，边际成本低、用户分层运营。
2. **角色一致性是漫剧命脉**：默认「文生图带参考图 + 固定 seed」保跨镜形象，直接文生视频仅作高级能力（当前模型一致性不可控）。
3. **积分一致性是资金安全线**：所有增减必须落流水 + 原子扣减，杜绝并发超发。
