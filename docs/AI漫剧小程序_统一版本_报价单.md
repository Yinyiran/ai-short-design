## 七、技术栈与交付

**技术栈**：UniApp-X（小程序端）+ NestJS（后端）+ Nest Admin/Vue3（管理端）+ MySQL 8 + Redis + BullMQ + COS；对接第三方 AI 开放 API（不做底层模型自研）。

**交付物**：小程序端源码、后端源码、管理端源码、数据库初始化脚本、部署文档、接口文档、后台操作手册；《隐私保护指引》《用户协议》提供**模板参考**（不代写法律文本，由客户在微信后台配置）。

**工期**：约 55–65 个工作日（单人，含联调与自测）。

**付款**：40% / 40% / 20%（启动 / 中期 Demo / 验收交付）。中期 Demo 由开发者**临时提供测试环境**供预览，不计入交付服务器。
